학습허브 설치 안내
==================

웹 주소
https://yangtary0511-alt.github.io/

[Windows 컴퓨터]
1. 이 폴더의 "학습허브.url"을 더블클릭합니다.
2. 학습허브 오른쪽 위의 "앱 설치"를 누릅니다.
3. 설치 창에서 "설치"를 누릅니다.

[Android 휴대폰]
1. 기존에 만든 학습허브 웹 바로가기가 있다면 먼저 삭제합니다.
2. Chrome에서 위 웹 주소를 직접 엽니다. "학습허브.url" 파일은 모바일에서 사용하지 않습니다.
3. 학습허브의 "앱 설치"를 누른 뒤 설치 창에서 "설치"를 누릅니다.
4. 설치된 "학습 허브" 아이콘으로 실행합니다. 주소 바로가기가 아니라 독립 앱 화면으로 열립니다.

[iPhone / iPad]
1. 기존에 만든 학습허브 웹 바로가기가 있다면 먼저 삭제합니다.
2. Safari에서 위 웹 주소를 직접 엽니다.
3. 아래쪽 공유 버튼을 누릅니다.
4. "홈 화면에 추가"를 누른 뒤 "추가"를 누릅니다.

[학습 기록 동기화]
모든 기기에서 같은 동기화 코드 0105를 사용합니다.
인터넷이 연결되면 기록이 자동으로 합쳐지고 저장됩니다.

[업데이트]
설치한 앱은 웹의 최신 버전을 자동으로 확인합니다.
앱이 열려 있었다면 완전히 닫았다가 다시 열면 최신 수정이 적용됩니다.
